Flow matching

发表于2026-07-27|更新于2026-07-29
|浏览量:

目的是从已知分布中得到目标分布。上图中 p0 是已知分布，p1 是目标分布。中间的过程称为 pkp_kpk​ 。各种 FM 方法本质上是在训练速度场的拟合，找出已知分布到目标分布速度场。

将速度场作为学习参数，真实的速度场的生成依赖路径的假设。

不带t的 P(x)

为了厘清 Flow Matching 中的 pt(x)p_t(x)pt​(x) 和普通的 p(x)p(x)p(x) 的区别，下面介绍一下普通的 p(x)p(x)p(x)。

p(x)p(x)p(x) 不是表示一副图像长什么样子，而是描述输入的 x 分布看起来像真实图片的概率。

假设考虑一张 100 px * 100 px 的图片，每个像素点只有灰度通道。那么这张图片有 10,000 个像素点，每个像素的值为 0~255。如果把这 10,000 个像素拍成一列，就构成了一个拥有 10,000 维的向量 xxx。这个向量的所有取值就包括了所有可能组成的图片。

p(x)p(x)p(x) 的意义是输入的 x 看起来有意义的概率有多大。由于 x 本身能取到所有 100 * 100 的灰度图片，造成了 p(x)p(x)p(x) 的如下特性：

  • 大部分区域的值很低，因为随机取一个 x，大概率无意义。
  • 极其狭窄扭曲的山峰，因为只有在满足极其严苛的物理分布规律时，比如勾勒出一只猫的形状，这个点, 也就是 x 才表示一张看起来真实的图片，p(x)p(x)p(x) 给出较高得分。
  • 山峰之间的连通性，比如白猫和黑猫之间，存在一条狭窄的路径可以让白猫渐变为黑猫，在这条路径上的 p(x)p(x)p(x) 都有比较高的取值。

回到 Flow Matching 中关心的 pt(x)p_t(x)pt​(x) ,随着时间的演进，pt(x)p_t(x)pt​(x) 表达的含义也有不同。p0(x)p_0(x)p0​(x) 表示 x 有多像最开始的分布, 而 p1(x)p_1(x)p1​(x) 表示 x 有多像最终的分布。当用于生成图片时，这里的 p1(x)p_1(x)p1​(x) 就是像真实照片的概率了。

其中 uθ(t,x)u_\theta(t,x)uθ​(t,x) 是预测速度场，utu_tut​ 是真实速度场。由于一般真实速度场没有 close form，不同的算法会假设不同的 ptp_tpt​ 分布。

Score Function

st(x)=∇x​log⁡pt​(x)s_t(x)=∇_x​\log p_t​(x) st​(x)=∇x​​logpt​​(x)

得分函数就是给分布取对数后求对 x 的导数，可以理解成把点拉向高概率区域。

结合我们之前对 pt(x)p_t(x)pt​(x) 的讨论，得分函数实际上指示了点集怎么运动能更像所需的目标分布 pt(x)p_t(x)pt​(x)

以高斯分布为例子，高斯分布的概率密度函数为

p(x)=12πσ2exp⁡((x−μ)2−2σ2)p(x)=\frac{1}{\sqrt{2 \pi \sigma ^ 2}}\exp (\frac{(x-\mu)^2}{-2\sigma^2}) p(x)=2πσ2​1​exp(−2σ2(x−μ)2​)

计算 Score Function 为

s(x)=x−μσ2s(x)=\frac{x-\mu}{\sigma ^ 2} s(x)=σ2x−μ​

所以当 x 大于 μ\muμ 时，x 增大得分下降，x 减小得分升高。形成了将点拉向高概率区域的场。

实际应用中，pt(x)p_t(x)pt​(x) 无法用数学公式描述，因此也无法求出其对数梯度; ddpm 等方法使用条件分布，让未知分布变得 tractable。具体细节如下一节所示。

使用条件分布
