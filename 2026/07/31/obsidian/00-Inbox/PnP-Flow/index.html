最大似然估计器

arg⁡max⁡x∈Rd{log⁡pX∣Y=y(x)}=arg⁡max⁡x∈Rd{log⁡pY∣X=x(y)+log⁡pX(x)}\arg\max_{x \in \mathbb{R}^d} \{\log p_{X\vert{}Y=y}(x)\} = \arg\max_{x \in \mathbb{R}^d} \{\log p_{Y\vert{}X=x}(y) + \log p_X(x)\} argx∈Rdmax​{logpX∣Y=y​(x)}=argx∈Rdmax​{logpY∣X=x​(y)+logpX​(x)}

后验概率 pX∣Y=y(x)p_{X\vert{}Y=y}(x)pX∣Y=y​(x) 表示在已知观测 yyy 的情况下，原始分布为 xxx 的概率。
套用贝叶斯公式：

pX∣Y=y(x)=pY∣X=x(y)⋅pX(x)pY(y)p_{X\vert{}Y=y}(x) = \frac{p_{Y\vert{}X=x}(y) \cdot p_X(x)}{p_Y(y)} pX∣Y=y​(x)=pY​(y)pY∣X=x​(y)⋅pX​(x)​

两边取对数后

log⁡pX∣Y=y(x)=log⁡pY∣X=x(y)+log⁡pX(x)−log⁡pY(y)\log p_{X\vert{}Y=y}(x) = \log p_{Y\vert{}X=x}(y) + \log p_X(x) - \log p_Y(y) logpX∣Y=y​(x)=logpY∣X=x​(y)+logpX​(x)−logpY​(y)

由于搜索器搜索的是 x 的解，log⁡pY(y)\log p_Y(y)logpY​(y) 可以看作是常数，不用写进最终的优化目标中。

由于实际问题中真实的图像分布 pX(x)p_X(x)pX​(x) 无法写出精确的数学表达式，而且在优化问题中更倾向于求解最小值，因此 MAP 搜索器在实际工作时会转化为能量最小化问题：

arg⁡min⁡x∈Rd{F(x)+R(x)}\arg\min_{x \in \mathbb{R}^d} \{F(x) + R(x)\} argx∈Rdmin​{F(x)+R(x)}

其中：

  • F(x):=−log⁡pY∣X=x(y)F(x) := -\log p_{Y\vert{}X=x}(y)F(x):=−logpY∣X=x​(y) (数据保真项) 。如果假设加性噪声 ξ\xiξ 是高斯噪声 N(0,σ2Id)\mathcal{N}(0, \sigma^2 I_d)N(0,σ2Id​)，那么这一项就可以写成最小二乘的形式 F(x)=12σ2∥Hx−y∥2F(x) = \frac{1}{2\sigma^2}\Vert{}Hx - y\Vert{}^2F(x)=2σ21​∥Hx−y∥2。
  • R(x)R(x)R(x) (正则化项/先验)： 取代了原来的 −log⁡pX(x)-\log p_X(x)−logpX​(x)，用于约束解的空间，确保存在唯一的最小值。

PnP

针对上面的能量最小化问题，由于 F(x)F(x)F(x) 容易有明确的表达式，而 R(x)R(x)R(x) 很难用数学公式定义，引入一个辅助变量 vvv，进行交替优化。

arg⁡min⁡x,v{F(x)+R(v)+λ2∥x−v∥2}\arg\min_{x,v} \left\{ F(x) + R(v) + \frac{\lambda}{2} \Vert{}x - v\Vert{}^2 \right\} argx,vmin​{F(x)+R(v)+2λ​∥x−v∥2}

正则项惩罚 vvv 与 xxx 的偏差。

更新 xxx

xk+1=arg⁡min⁡x{F(x)+λ2∥x−vk∥2}x_{k+1} = \arg\min_{x} \left\{ F(x) + \frac{\lambda}{2} \Vert{}x - v_k\Vert{}^2 \right\} xk+1​=argxmin​{F(x)+2λ​∥x−vk​∥2}

与 R(x)R(x)R(x) 解耦后，不涉及 ODE 问题，直接反向传播更新。

Note

如果不使用交替优化，x 的更新公式中就会包含 R(x)R(x)R(x)。而 R(X)R(X)R(X) 依赖 ODE 求解，反向传播更新 x 的过程中梯度会穿过 ODE 求解器，导致灾难性的数值问题。

更新 vvv

vk+1=arg⁡min⁡v{λ2∥xk+1−v∥2+R(v)}v_{k+1} = \arg\min_{v} \left\{ \frac{\lambda}{2} \Vert{}x_{k+1} - v\Vert{}^2 + R(v) \right\} vk+1​=argvmin​{2λ​∥xk+1​−v∥2+R(v)}

这一步等价于

已知一张带有方差为 1/λ1/\lambda1/λ 高斯噪声的图像 xk+1x_{k+1}xk+1​，求它去噪后的干净图像 vvv。

于是 R(x)R(x)R(x) 可以直接换成现有的去噪器，比如 BM3D,Unet,FlowMatching。这一步便被称为即插即用。

每一次迭代，xxx 负责逼近物理观测，vvv（去噪器）负责把逼近过程中产生的伪影和噪声抹平。两者交替上升，最终收敛到完美的高清图像。

主要包含三个步骤：

  1. 梯度下降。对应 F(x)F(x)F(x) 的优化
  2. 插值。由于 Flow Matching 是依赖时间的，如果走完第一步后偏离最优传输路径太多，会出现严重的计算误差。
  3. 去噪。调用 Flow Matching 去噪器进行去噪，执行一次前向 ODE 积分步

Lipschitz 常数

Lipschitz constant 的定义是 f(x)f(x)f(x) 满足

∥f(x1)−f(x2)∥≤L∥x1−x2∥\Vert{}f(x_1) - f(x_2)\Vert{} \leq L \Vert{}x_1 - x_2\Vert{} ∥f(x1​)−f(x2​)∥≤L∥x1​−x2​∥

对定义域内任意两点 x1,x2x_1, x_2x1​,x2​ 都成立，那么这个函数是 Lipschitz 连续的。LLL 就是满足这个不等式的最小常数。

如果 L≤1L \leq 1L≤1 ，意味着输出的差异不会大于输入的差异，函数不会放大误差。这在神经网络训练中非常重要，有利于算法收敛。但是限制 Lipschitz 常数也会限制神经网络的表达能力，使其无法拟合边缘和纹理等变化陡峭的图像元素，导致输出的图形非常模糊。
